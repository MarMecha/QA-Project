Full-stack web application developed for managing university quality assurance processes.

The system supports role-based access, evaluation workflows and centralized academic data management through RESTful APIs.

Features: 

✔ User Authentication
✔ Role-Based Authorization
✔ REST API Architecture
✔ University Evaluation Management
✔ Relational Database Integration
✔ Frontend Dashboard
✔ CRUD Operations

Tech Stack: 

Backend
- Java
- Spring Boot
- Spring Security
- REST APIs

Database
- PostGreSQL

Frontend
- HTML
- CSS
- JavaScript


Authentication implemented using JWT.

Authorization supports multiple user roles with protected endpoints.

Backend Architecture:
- Backend implemented using Spring Boot following layered architecture principles.
- Persistence handled through Spring Data JPA and Hibernate.
- Entity relationships designed using ORM mappings.

- Full-stack application integration
